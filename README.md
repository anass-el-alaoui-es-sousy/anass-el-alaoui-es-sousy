## Projets principaux

### Application de domotique — Python / Tkinter / unittest

Application de bureau conçue et développée intégralement en Python/Tkinter pour gérer les équipements d’une maison.

Fonctionnalités principales :

* gestion dynamique des pièces et des groupes ;
* contrôle de l’éclairage, des volets et des températures ;
* définition d’une température cible commune pour un groupe ;
* programmation d’automatismes horaires ;
* validation du format des heures ;
* détection des doublons et des conflits ;
* nettoyage des dépendances lors des suppressions ;
* activation et désactivation des automatismes.

Le projet comprend **65 tests unitaires automatisés** couvrant notamment les règles métier, les validations, les conflits, les températures et l’exécution des automatismes.
